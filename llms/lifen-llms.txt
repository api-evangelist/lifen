## API Reference
- [Authenticate application](https://developer.lifen.fr/reference/authenticate-application.md): Accessing Lifen's APIs in Machine To Machine involves obtaining an Access Token with the Client credentials grant flow of OAuth 2.0 from a back-end server.  Get a token :  A request to Lifen must be perfomed to generate an access token. In the request, the client has to provide his credentials and some configuration.  Perform an API call : The Access Token allows you to make requests to the API on the behalf of the client. Each request must include the Access Token in the Authorization header using the Bearer format.  Example : `curl -H "Authorization: Bearer $ACCESS_TOKEN" https://api.lifen.fr/fhir/v3/$endpoint`
